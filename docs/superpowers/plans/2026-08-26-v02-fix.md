# IaaS Inspection Platform v0.2 修复实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将当前 v0.2 骨架收口为可执行、可恢复、可追溯的 React 橙白巡检体验，并补齐真实 AI、证据、资源风险和 CI 验收链路。

**Architecture:** Manual Run 在创建时绑定确定性的 MockDataset，并通过提交后异步任务运行单一 orchestrator；orchestrator 直接调用现有 batch domain services，所有阶段写入 durable events。Resource Investigation 与 Ask AI 复用已有 LangGraph、Capability Registry 和只读模型 Gateway，HTTP 只负责创建记录，后台任务负责执行，前端通过可恢复的 SSE/轮询读取状态。

**Tech Stack:** Django 4.2、PostgreSQL、LangGraph、现有 ModelGateway/CapabilityRegistry、React、TypeScript、React Query、Vitest、Playwright、GitHub Actions。

**Spec:** `/Users/lars.li/Downloads/iaas-inspection-platform-v0.2-fix-plan.md`

## Global Constraints

- 当前工作分支保持 `codex/v0.2-resource-inspection`。
- Manual Run 使用 `MockDataset` 作为 v0.2 execution context；不得在执行阶段重新解析冻结 scope。
- AI 保持 Code-first、AI-on-demand、只读 Capability、Evidence-backed conclusion。
- 所有环境选项来自 `GET /api/v1/environments`，不得继续硬编码环境 slug。
- 正式 Web 路由统一由 React SPA 提供，API/SSE 继续由 Django 提供。
- 设计文档和本计划不加入 Git 提交。
