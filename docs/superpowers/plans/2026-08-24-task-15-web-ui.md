# Task 15 Web UI and Product About Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver the Task 15 web shell, risk AI drawer, capability/evolution views, and product explanation page on top of the existing public REST API.

**Architecture:** Django serves one authenticated-agnostic HTML shell for the dashboard and navigation routes plus a dedicated product-about document. Vanilla ES modules fetch the existing `/api/v1/` projections, render safe summaries by default, and keep evidence/tool details inside closed `<details>` elements. No new frontend dependency or backend domain model is introduced.

**Tech Stack:** Django 4.2.16 templates/static files, semantic HTML, CSS, browser ES modules, existing JSON/SSE REST APIs.

**Spec:** `设计文档/IaaS智能巡检平台_开发实施文档_v1.md` sections 17, 38–49, 55–56.

## Global Constraints

- UI 默认简洁，Evidence、Tool Call、内部状态、Raw JSON 默认折叠。
- 首页默认不显示 Raw JSON、Prompt、Tool 参数。
- 风险详情提供 AI 对话 Drawer、反馈和“记录已处理”入口。
- 每个巡检项目显示 `execution_mode`、`code_status`、`code_coverage_percent`、`llm_responsibilities`。
- 能力演进页显示 Code Coverage Rate、Deterministic Deflection Rate 和 AI Displacement Rate。
- 产品说明页覆盖第 56 节列出的 12 个主题。
- 使用浏览器原生 ES modules/CSS，不增加依赖。
- 按用户要求，在 Task 15 实现代码完成前不执行测试命令。
